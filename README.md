# House Prices - Advanced EDA & Feature Engineering

## Project Overview

This project performs Advanced Exploratory Data Analysis (EDA) and Feature Engineering on the House Prices dataset.

## Tasks Completed

- Data Loading
- Exploratory Data Analysis
- Missing Value Handling
- Outlier Detection using IQR
- Feature Engineering
- Data Visualization
- Clean Dataset Generation

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

House Prices Dataset (Kaggle)

## Output

Cleaned_House_Prices.csv
